# S3.17: river events

S3.17 adds **river events** (`crates/race-core/src/sim/river.rs`): two race-wide, telegraphed events per
race. Nothing else in the engine changed. The goal is a race that stays open to the end, for the win and
for last place alike (the Chaos losers matter as much as the winner).

## Why

`race-cli balance drama` (new in this version, `crates/race-cli/src/drama.rs`) measures how predictable
a race is while it runs: at each checkpoint, how often the duck in front wins, how often the duck at the
back finishes last, and how well the running order predicts the final order. On S3.16 the first half of
the race was already open, but the last quarter was flat: the leader at 75 % won 44 % of races, and 39 %
of races had no lead change after 75 %.

Design references (what similar games do, and the pitfalls): Mario Kart keys item strength to the
distance from the leader and locks its field-wide items out of the opening; Camel Up and marble races get
their drama from late swings nobody controls; suspense research (Ely, Frankel, Kamenica 2015) says
uncertainty should fall gradually, not flip in the last second; hidden rubber-banding reads as rigging.
So the events are public, the same for every duck, announced on screen before they start, and none starts
after about 89 % of the race.

## Rules

Each race rolls two different events from its seed (stream `river-events`): one announced when the
leader's progress reaches a point in 36–54 %, one in 74–84 %. An event is announced 2.5 s before it
starts (`RIVER_EVENT_WARNING`), then runs (`RIVER_EVENT_STARTED` … `RIVER_EVENT_ENDED`). While it runs it
multiplies how far a duck moves per tick, on top of the track current and item effects. It never stops,
reverses or teleports a duck and does not touch items or pickups. Events never overlap.

| Event | Duration | Effect |
|---|---|---|
| Flash flood | 4.0 s | speed × (1 + min(0.18, 4.0 × gap to the leader in progress)), recomputed every tick |
| Whirlpool | 2.2 s | the ducks ranked 1 / 2 / 3 when it starts: × 0.78 / 0.84 / 0.90 |
| Gust | 3.0 s | every duck: its own multiplier in 0.86–1.13, drawn from the seed |
| Bread rain | 3.0 s | the back half when it starts: last duck × 1.13, fading linearly to × 1 at the middle |

Constants: `sim::river::river_balance`. Player-facing copy: `src/season3/season3-rules-content.ts`
(`RIVER_EVENTS_LIST`) and `components/racing/river-event-copy.ts`. `ts-compat` builds have no river
events, so the S3.15 oracle tests are unchanged.

## Result

`race-cli balance drama --races 4000` (8-duck production lobbies; raw output in
`artifacts/balance-s3-17/`; the S3.16 column is 2000 races of the same seeds):

| Metric | S3.16 | S3.17 |
|---|---|---|
| leader at 50 % wins | 32.5 % | 19.6 % |
| leader at 75 % wins | 44.3 % | 29.8 % |
| leader at 90 % wins | 66.5 % | 55.2 % |
| leader at 97 % wins | 86.9 % | 83.3 % |
| last at 75 % finishes last | 27.1 % | 20.3 % |
| last at 90 % finishes last | 45.0 % | 41.4 % |
| winner was in the bottom half at 75 % | 12.6 % | 25.1 % |
| final loser was in the top half at 75 % | 26.2 % | 38.4 % |
| order correlation at 50 % / 75 % / 90 % | 0.30 / 0.46 / 0.71 | 0.08 / 0.27 / 0.63 |
| races with no lead change after 75 % | 39.2 % | 26.8 % |
| races with no last-place change after 75 % | 21.9 % | 16.3 % |
| lead changes per race (after 75 %) | 3.80 (0.96) | 4.23 (1.26) |
| median gap 1st to 2nd | 425 ms | 335 ms |
| photo finishes (< 150 ms) for the win / for last | 21.4 % / 22.6 % | 24.7 % / 23.3 % |
| first-to-last spread (median) | 2.50 s | 2.27 s |

The outcome still settles gradually (order correlation 0.63 at 90 %, 0.89 at 97 %): the events shuffle
the middle and the start of the final stretch, not the last metres.

Balance (`race-cli balance mixed --races 2000`, 8 ducks, NORMAL) stayed inside the noise:

| | S3.16 win % | S3.17 win % |
|---|---|---|
| ATTACK loadouts | 13.97 | 13.42 |
| DEFENSE loadouts | 11.56 | 12.22 |
| SPEED loadouts | 11.98 | 11.87 |
| temperaments (min–max) | 11.91–12.97 | 12.20–13.06 |

Race length is unchanged (mean 57.4 s against 57.6 s).

Known trade-off: leading early is now slightly worse than chance (the leader at 25 % wins 11.8 %, chance
12.5 %; S3.16: 17.3 %). A first tuning pass with stronger events pushed this to 9.9 % and was rejected.
